# almondweisley.github.io

My portfolio site, served by GitHub Pages at **https://almondweisley.github.io**.

It covers my featured projects (Whetstone, Oloonkerin Management, Azani ISP Information System, YelenImport), smaller work, skills with links to the code behind them, experience, education, a contribution timeline, and how to reach me.

## Structure

| File | Purpose |
|---|---|
| `index.html` | The whole site: markup, styles and a small script, with no build step |
| `avatar.jpg` | Profile photo, also used as the link-preview image |
| `.nojekyll` | Tells GitHub Pages to serve the files as they are |

## Updating

Edit `index.html` and open a pull request into `main`. Pages redeploys a minute or two after the merge.

The contribution chart reads from the `data` array near the bottom of `index.html`. Update it when the numbers change.
